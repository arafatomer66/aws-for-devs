# S3 — Simple Storage Service

**TL;DR** — Object storage. Practically infinite, 11 nines of durability, pay-per-GB. The most-used AWS service. If in doubt, "put it in S3."

## What it is

A blob store. You create a **bucket** (globally unique name), put **objects** (any byte blob up to 5 TB each) into it under a **key** (e.g. `users/42/avatar.jpg`). Access via HTTPS or SDK.

S3 is the foundation of almost every AWS workload — static sites, data lakes, backups, ML training data, event sources, you name it.

## Why it exists

Before S3 (2006), storing TBs of files meant SAN/NAS or building your own object store. S3 gave you "unlimited durable disk on the internet" at commodity prices.

## Key concepts

- **Bucket** — top-level container. **Globally unique name** across all AWS. Belongs to one region.
- **Object** — a file (key + value + metadata).
- **Key** — the path-like string (S3 has no real folders, just `/` in keys).
- **Storage class** — pricing tier (Standard, IA, Glacier, etc.).
- **Versioning** — keep old versions of objects.
- **Lifecycle rules** — auto-transition old data to cheaper tiers, or delete.
- **Bucket policy** — resource-based JSON policy.
- **Block Public Access (BPA)** — account+bucket-level kill switch for public buckets (on by default).
- **Pre-signed URL** — short-lived URL that grants get/put without IAM credentials.
- **Multipart upload** — chunked upload (required for objects > 5 GB).
- **Transfer Acceleration** — upload via CloudFront edge for big files.
- **Replication** — cross-region (CRR) or same-region (SRR).
- **Event notifications** — on-create/delete events → Lambda / SQS / SNS / EventBridge.

## Storage classes

| Class | Cost ($/GB-mo) | Min duration | Retrieval | Use |
|---|---|---|---|---|
| Standard | $0.023 | — | instant | Hot data, default |
| Intelligent-Tiering | $0.023 + $0.0025 monitor fee | — | instant | Unknown access patterns |
| Standard-IA | $0.0125 | 30 days | instant | Backups accessed monthly |
| One Zone-IA | $0.01 | 30 days | instant | Re-creatable data |
| Glacier Instant Retrieval | $0.004 | 90 days | instant | Archive, rare access |
| Glacier Flexible Retrieval | $0.0036 | 90 days | mins–hrs | Old archives |
| Glacier Deep Archive | $0.00099 | 180 days | 12 hrs | Cold compliance archive |

Plus **GET/PUT request charges** vary per class.

## Real-world example

> ShareDeal stores product images and user-uploaded receipts:
>
> - `selefe-uploads/products/{id}/{filename}` — Standard tier, served via CloudFront.
> - `selefe-uploads/receipts/{user-id}/{date}.pdf` — Standard for 30 days → Standard-IA → Glacier after 1 year.
> - Versioning on, so accidental deletes can be restored.
> - Bucket policy blocks all public access; CloudFront uses an OAC (Origin Access Control) to read.

## Usage

### Create a bucket

```bash
aws s3 mb s3://my-unique-bucket-name --region ap-south-1
```

### Upload / download

```bash
aws s3 cp file.pdf s3://my-bucket/path/file.pdf
aws s3 cp s3://my-bucket/path/file.pdf ./
aws s3 sync ./local-dir s3://my-bucket/remote-dir/
aws s3 ls s3://my-bucket/path/
```

### From Node SDK (v3)

```js
import { S3Client, PutObjectCommand, GetObjectCommand } from "@aws-sdk/client-s3";
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";

const s3 = new S3Client({ region: "ap-south-1" });

await s3.send(new PutObjectCommand({
  Bucket: "my-bucket",
  Key: "users/42/avatar.jpg",
  Body: fileBuffer,
  ContentType: "image/jpeg",
}));

// Pre-signed URL valid for 1 hour
const url = await getSignedUrl(
  s3,
  new GetObjectCommand({ Bucket: "my-bucket", Key: "users/42/avatar.jpg" }),
  { expiresIn: 3600 },
);
```

### Pre-signed upload (client-direct)

Generate URL server-side, browser PUTs directly — no traffic through your server:
```js
const url = await getSignedUrl(
  s3,
  new PutObjectCommand({ Bucket: "uploads", Key: `temp/${uuid()}`, ContentType: "image/jpeg" }),
  { expiresIn: 600 },
);
return { uploadUrl: url };
```

### Lifecycle rule (move + delete old)

```json
{
  "Rules": [{
    "ID": "archive-old-receipts",
    "Filter": { "Prefix": "receipts/" },
    "Status": "Enabled",
    "Transitions": [
      { "Days": 30,  "StorageClass": "STANDARD_IA" },
      { "Days": 365, "StorageClass": "GLACIER" }
    ],
    "Expiration": { "Days": 2555 }
  }]
}
```

```bash
aws s3api put-bucket-lifecycle-configuration --bucket my-bucket --lifecycle-configuration file://lifecycle.json
```

### Static website hosting

```bash
aws s3 sync ./dist s3://my-site --delete
aws s3 website s3://my-site --index-document index.html --error-document 404.html
```

Better: put CloudFront in front, use OAC for private origin.

### Versioning

```bash
aws s3api put-bucket-versioning --bucket my-bucket \
  --versioning-configuration Status=Enabled
```

## Security

- **Block Public Access** on by default. Don't disable unless you really mean it.
- **Bucket policy** for resource-based access:
```json
{
  "Statement": [{
    "Effect": "Allow",
    "Principal": { "Service": "cloudfront.amazonaws.com" },
    "Action": "s3:GetObject",
    "Resource": "arn:aws:s3:::my-bucket/*",
    "Condition": { "StringEquals": { "AWS:SourceArn": "arn:aws:cloudfront::..:distribution/..." } }
  }]
}
```
- **Server-side encryption** — SSE-S3 (default, AWS keys) or SSE-KMS (your KMS key, audited). Enabled by default since 2023.
- **HTTPS only** — set a bucket policy `aws:SecureTransport = true`.
- **VPC endpoints (gateway type)** — free, keep S3 traffic off the public internet.

## Pricing model

- **Storage:** per GB-month, varies by class.
- **Requests:** PUT $0.005/1k, GET $0.0004/1k (Standard).
- **Data transfer OUT to internet:** ~$0.09/GB.
- **Data transfer IN:** free.
- **Cross-region replication:** transfer cost + 2x storage.

A 100 GB Standard bucket with normal traffic ≈ **$3-5/mo**.

## Performance

- **Read/write throughput** scales automatically. ~3,500 PUT/COPY/POST/DELETE and ~5,500 GET/HEAD per second per *prefix*.
- For huge throughput, sharding keys across prefixes is no longer needed (improved 2018+).
- **S3 Transfer Acceleration** routes through CloudFront PoPs — faster long-haul uploads.
- **Multipart upload** required for objects > 5 GB, recommended for > 100 MB.

## Gotchas

- **Bucket names are global.** First-come, first-served across all AWS accounts.
- **Eventual consistency was a gotcha — gone since Dec 2020.** S3 is now strongly consistent for all operations.
- **Deletions are permanent unless versioning is on.** Turn on versioning + MFA Delete for critical buckets.
- **Lifecycle rules don't apply retroactively to all versions** — read the docs carefully.
- **`s3://` URLs aren't HTTP URLs.** Use `https://<bucket>.s3.<region>.amazonaws.com/<key>`.
- **Cross-region transfer is expensive** ~$0.02/GB. Plan replication carefully.
- **S3 Glacier Deep Archive has a minimum 180-day storage charge** — putting + immediately deleting still costs you.
- **A bucket per environment, per service** — don't share buckets across teams. Easier IAM scoping.
- **Pre-signed URLs leak permissions if shared.** Short TTLs, restrict to specific keys.
